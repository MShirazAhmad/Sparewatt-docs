# Keyboard shortcuts

These work from any app. They are the defaults: you can change each one, or turn it off.

| Keys | Does |
|---|---|
| ⌥⌘R | open the dashboard |
| ⌥⌘V | open the Files panel (Latest File, Shelf, clipboard) |
| ⌥⌘E | turn Extreme Saver on or off (not on a Mac with no battery) |

## Changing them

Dashboard → **Shelf, Profiles & Alerts** → *Keyboard shortcuts* lists all three; the dashboard's is also on Dashboard →
**Menu Bar** → *General*.

- Click a shortcut, then press the new keys. **Esc** cancels; **Delete** turns that shortcut off (it then reads *Off*).
- The arrow beside a changed shortcut puts back its default.
- A shortcut needs **⌥** or **⌃** (or **⌘⇧** together), so it doesn't take a key you type or an app's own menu
  command. A function key (F1–F20) may be used on its own.
- Keys macOS itself uses are refused, with the reason: screenshots (⌘⇧3 to ⌘⇧6), Lock Screen (⌃⌘Q), Emoji & Symbols
  (⌃⌘Space), switching input sources (⌃Space, ⌃⌥Space), Force Quit (⌥⌘Esc), the Dock (⌥⌘D), the Help menu (⌘⇧/),
  Mission Control and Spaces (⌃ with an arrow). So is a shortcut another of Sparewatt's already uses.
- If macOS doesn't accept a shortcut (another app may already have it), Sparewatt says so and keeps the old one.

While you are pressing new keys, none of Sparewatt's shortcuts fire. The shortcuts are part of the
[settings export](../features/11%20Dashboard%2C%20history%20and%20this%20app.md#your-settings-export-import-welcome-again),
so an imported file brings its shortcuts with it. They need no permission in System Settings.

## Other keys

In the menu bar: hover a part to open its panel, right-click for the dashboard, settings, Extreme Saver and Quit.
With grouping off, hold ⌘ and drag an item to move it.

To run these from Shortcuts or a script, use
[links for Shortcuts and scripts](Links%20for%20Shortcuts%20and%20scripts.md) (`sparewatt://…`).
