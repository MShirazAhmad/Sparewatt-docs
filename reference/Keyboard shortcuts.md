# Keyboard shortcuts

These work from any app.

| Keys | Does |
|---|---|
| ⌥⌘R | open the dashboard |
| ⌥⌘V | open the Storage panel (Latest File, Shelf, clipboard) |
| ⌥⌘E | turn Extreme Saver on or off |

The same list is on Dashboard → **Shelf, Profiles & Alerts**.

In the menu bar: hover a part to open its panel, right-click for the dashboard, settings, Extreme Saver and Quit.
With grouping off, hold ⌘ and drag an item to move it.
