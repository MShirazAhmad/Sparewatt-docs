# Mac drop-zone / shelf apps — what reviewers say, and what fits Sparewatt

Researched 2026-11-04 (web search; few direct complaint threads exist, so this leans on reviews, App Store listings and forums).

| App | What it is | Praised | Criticised |
|---|---|---|---|
| Dropzone 4 | menu bar drop target with actions (move, copy, upload, AirDrop, scripts) | deepest action set | moved to subscription (Macworld); no floating drop box (Setapp reviewer switched to Yoink for that) |
| Yoink | floating shelf at the screen edge | floating box, works in full screen and across Spaces, stacks many files, has clipboard snippets | fewer actions than Dropzone; "limited in essential features and customisability" (Product Hunt) |
| Dropover | shelf summoned by shaking the cursor mid-drag; notch drop | most recommended; shake gesture | free tier waits 3 s per use; trial/free limits unclear (MacUpdate); shake sometimes unresponsive; no clipboard history; Mac App Store only |
| Unclutter | pull-down panel: files, clipboard, notes | three tools in one | paid; breaks on some macOS updates (listing text) |
| NotchNook | notch panel with a file tray | notch use | "buggy" — files could be dropped in but not dragged back out (MacPowerUsers) |
| Droppy | open-source notch + floating shelf | free at start | became paid; very new (Jan 2026) |
| Dockside, ExtraDock, Perch, FlowShelf | drop zones next to the Dock, per-monitor shelves, free shelves | drop zones with set actions; multi-monitor | little independent review |

## Recurring user wishes
1. A drop target that is always where the pointer is (floating, shake, notch, menu bar).
2. Drag out works as well as drag in — move, not only copy.
3. No subscription and no nag delays.
4. Clipboard history in the same place as the shelf.
5. One-drop actions: move to a set folder, AirDrop, zip, copy path, open with.
6. Works in full screen, across Spaces and on every monitor.

## What Sparewatt already has
Latest File (drag the newest file out, plus 4 more), clipboard history with pins and plain-text paste — free, no nag, in the menu bar.

## What to add (best value first)
1. **Drop onto the menu bar item** → a Shelf card in the Storage panel. Holds references (no copy), shows a stack, drag back out (all at once or one by one), survives restart.
2. **Drop actions** on the shelf: Move to… (chosen folders), AirDrop, Zip, Copy path, Open with, Trash.
3. **Shake to summon** a small floating shelf at the pointer during any drag (setting, off by default) — answers the "always reachable" wish; works in full screen.
4. **Folder drop zones**: pinned folders in the shelf (Downloads, Vault inbox, a paper folder) — drop a file on one to move/copy it there.
5. **Latest File → shelf** with one click, so the newest screenshot/export can be collected over a few minutes and dropped together.
6. Keep it free, local and nag-free; per-monitor placement follows the screen the pointer is on.
